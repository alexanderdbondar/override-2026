# Controller bindings

Bindings from the last build (see archive/last-build-88w/main.cpp). Kept as a reference for the new build; change deliberately if the new build binds differently.

| Binding | Action |
|---|---|
| Axis3 + Axis1 | split arcade drive, both reversed |
| Axis3 + Axis2 | tank drive, both reversed |
| X + B (tap both) | toggle tank / arcade |
| R1 / R2 | lift up 65% / down 50%, manual beats presets |
| Up / Right / Down | lift presets: high 1650, mid 900, rest 0 |
| Down + A (hold) | re-zero the lift at the bottom |
| L1 / L2 | intake in 100% / out 80% (hold) |
| Y | grip latch toggle at 35% |
| X / B | tilt vertical 0 / horizontal 450, tap one not both |
| A (tap) | handoff macro: vertical, feed, horizontal |
| Left (tap) | grip release, reverse 80% for 450ms, clears lift fault |
| Left (hold 1s) | e-stop manipulators, clears lift desync fault |

Bindings for the new build get written here as they are decided.
